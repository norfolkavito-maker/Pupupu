# README — Local AI Agent Workflow Pack

Этот набор файлов («agent pack») предназначен для **локальной работы AI‑агентов**
внутри этого репозитория.

## Зачем это нужно

1. Делает требования и правила **частью репозитория**, а не «контекстом чата».
2. Позволяет агенту работать воспроизводимо:
   - читать task/acceptance файлы;
   - вести прогресс;
   - фиксировать блокеры;
   - запускать верификацию.
3. Упрощает onboarding новых агентов/моделей.

## Где лежат основные файлы

- `AGENTS.md` — универсальные правила (source of truth, no invented features, verification и т.д.).
- `LOCAL_AGENT_START_HERE.md` — copy‑paste промпты для старта.
- `docs/ai/MASTER_TASK.md` — главный «контракт задачи».
- `docs/ai/prompts/*.md` — файлы для больших промптов (их удобно хранить в репо).
- `docs/ai/ACCEPTANCE_CHECKLIST.md` — чеклист приемки.
- `docs/ai/PROGRESS.md` — прогресс по милстоунам.
- `docs/ai/BLOCKERS.md` — блокеры (только реальные).
- `scripts/agent-verify.ps1`, `scripts/agent-verify.sh` — запуск верификации.

## Куда вставлять 4 больших промпта

Заглушки лежат тут:
- `docs/ai/prompts/01-core-foundation.md`
- `docs/ai/prompts/02-ui-ux.md`
- `docs/ai/prompts/03-tests-diagnostics.md`
- `docs/ai/prompts/04-release-polish.md`

Каждый файл содержит структуру и пометку **"Replace this placeholder with the real prompt."**
— замени содержимое на реальный промпт, сохраняя секции.

## Как стартовать агента

1. Открой `LOCAL_AGENT_START_HERE.md`.
2. Скопируй **полный стартовый промпт**.
3. Вставь его в агент/IDE.
4. Убедись, что агент:
   - читает `AGENTS.md` и `docs/ai/MASTER_TASK.md` перед изменениями;
   - работает маленькими милстоунами;
   - после каждого милстоуна запускает `scripts/agent-verify.*`;
   - обновляет `docs/ai/PROGRESS.md`.

## Почему промпты — файлами в репозитории

- Это прозрачно: ревью и история изменений в git.
- Это воспроизводимо: CI/локальная среда всегда видит одинаковые инструкции.
- Это удобно: можно ссылаться на конкретные требования по путям.

## Обновление PROGRESS / BLOCKERS

- После каждого заметного изменения — обновляй `docs/ai/PROGRESS.md`.
- `docs/ai/BLOCKERS.md` заполняй **только** если без человека (доступы/секреты/решения)
  продолжить нельзя. Всегда добавляй точные команды и ошибки.
