# Strategy Model

Этот документ описывает модель стратегий DedZapret Manager. Модель охватывает структуру, типы, управление и жизненный цикл стратегий.

---

## 1. Основные понятия

### 1.1 Стратегия
**Стратегия** — это набор правил и параметров для обхода DPI с помощью winws2. Каждая стратегия содержит:
- **Идентификатор** — уникальное имя
- **Тип** — классификация по методу обхода
- **Конфигурация** — параметры для winws2
- **Слои** — базовая + дополнительные настройки

### 1.2 Компоненты стратегии
**Основные компоненты:**
- **Базовая стратегия** — основные параметры обхода
- **Yv слой** — параметры для Yandex.VPN
- **Dv слой** — параметры для Divert
- **Gv слой** — параметры для Gaming
- **Списки** — файлы списков доменов

### 1.3 Типы стратегий
**Классификация по методу обхода:**
- **DNS** — обход через DNS
- **TCP** — обход через TCP
- **UDP** — обход через UDP
- **Combo** — комбинированный метод

### 2.2 Параметры стратегии
**Базовые параметры:**
- **method** — метод обхода (auto/dns/tcp/udp)
- **fake** — путь к fake файлу
- **list** — путь к списку доменов
- **hostlist** — путь к hosts файлу
- **timeout** — таймаут в секундах
- **threads** — количество потоков

**Слоевые параметры:**
- **enabled** — включение слоя
- **fake** — специфичный fake файл
- **list** — специфичный список доменов
- **hostlist** — специфичный hosts файл

### 2.3 Версионирование

### 4.2 Валидация стратегий
**Проверки:**
- **Структура** — соответствие JSON schema
- **Параметры** — валидные значения
- **Файлы** — существование файлов
- **Совместимость** — с системой
- **Конфликты** — с другими стратегиями

**Валидация:**
```python
def validate_strategy(strategy: Strategy) -> List[str]:
    errors = []
    
    # Проверка структуры
    if not strategy.id:
        errors.append("Missing strategy ID")
    
    # Проверка файлов
    if not os.path.exists(strategy.base.fake):
        errors.append(f"Fake file not found: {strategy.base.fake}")
    
    # Проверка совместимости
    if not is_compatible(strategy):
        errors.append("Strategy not compatible with system")
    
    return errors
```

### 4.3 Регистрация стратегий
**Реестр стратегий:**
- **Хранение** — в памяти + файл
- **Индексация** — по ID, типу, тегам
- **Поиск** — быстрый поиск
- **Кэш** — для производительности

**Операции с реестром:**
```python
# Добавление стратегии
registry.add(strategy)

# Получение стратегии
strategy = registry.get("v8-dns-tcp-udp")

# Поиск стратегий
strategies = registry.search(type="combo", tags=["gaming"])

# Удаление стратегии
registry.remove("v8-dns-tcp-udp")
```

## 6. Композиция стратегий

### 6.1 Сборка стратегии
**Процесс сборки:**
1. Базовая стратегия
2. Применение Yv слоя
3. Применение Dv слоя
4. Применение Gv слоя
5. Финальная валидация

**Пример сборки:**
```python
def build_strategy(base_id: str, layers: dict) -> Strategy:
    # Загрузка базовой стратегии
    base = get_strategy(base_id)
    
    # Клонирование для изменений
    strategy = copy.deepcopy(base)
    
    # Применение слоев
    if layers.get('Yv', {}).get('enabled'):
        apply_layer(strategy, 'Yv', layers['Yv'])
    
    if layers.get('Dv', {}).get('enabled'):
        apply_layer(strategy, 'Dv', layers['Dv'])
    
    if layers.get('Gv', {}).get('enabled'):
        apply_layer(strategy, 'Gv', layers['Gv'])
    
    return strategy
```
