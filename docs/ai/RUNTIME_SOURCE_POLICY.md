# Runtime Source Policy

Этот документ описывает политику ролей upstream-источников для DedZapret Manager. Политика определяет, как использовать и интегрировать внешние источники в проекте.

---

## 1. Введение

### 1.1 Цель политики
**Основные цели:**
- **Четкое разделение** — роли и ответственности между источниками
- **Безопасная интеграция** — безопасное использование внешнего кода
- **Качество и надежность** — высокое качество конечного продукта
- **Соответствие лицензиям** — соблюдение лицензионных требований

### 1.2 Область применения
**Политика применяется к:**
- Внешним бинарным файлам
- Внешним скриптам и конфигурациям
- Внешним стратегиям и конфигурациям
- Внешним библиотекам и зависимостям
- Внешним API и сервисам

## 4. Безопасная интеграция

### 4.1 Binary Files
**Обработка бинарных файлов:**
- **Проверка хешей** — проверка контрольных сумм
- **Проверка подписей** — проверка цифровых подписей
- **Вирусная проверка** — проверка на вирусы
- **Изоляция** — изоляция от основной системы

**Пример:**
```python
def verify_binary(binary_path):
    # Проверка хеша
    expected_hash = "sha256:..."
    actual_hash = calculate_sha256(binary_path)
    
    if actual_hash != expected_hash:
        raise SecurityError("Hash mismatch")
    
    # Проверка подписи
    if not verify_signature(binary_path):
        raise SecurityError("Invalid signature")
    
    # Вирусная проверка
    if scan_for_viruses(binary_path):
        raise SecurityError("Virus detected")
```

**Пример:**

def import_flowseal_strategy(bat_content):
    # Парсинг .bat файла
