## v0.3.5-test.10

This is a test/staging release that bundles the latest P0/P1 stabilization work.

### Highlights
- Fixed strategy loader crash on `generated/index.json`.
- Flowseal helper/service `.bat` files are no longer imported as strategies.
- Flowseal placeholders and asset preflight diagnostics added.
- Builtin v3/v8 fake asset diagnostics and repair compatibility.
- sing-box subscription import improved.
- Pasted http(s) link into single node import now shows guidance instead of crashing.
- Active sing-box node auto-select after successful subscription update.
- sing-box health report added.
- Test all strategies with progress, ranking, and JSONL telemetry.
- Problem Domains v2 storage, strict test set behavior, bug report integration.
- Diagnostics artifacts for runtime assets, Flowseal assets, and latest strategy ranking.
- winws2 compatibility diagnostics and repair.
- Unified commands layer added for future tray/GUI/compact mode.

### Notes / known limitations
- V2Ray/Xray backend is not implemented yet.
- Real sing-box `check -c` validation is future work.
- Tray/watcher modules are included but optional/experimental; they do not auto-start unless explicitly enabled and require extra dependencies.

### Verification
- `python3 -m pytest -q`: PASS (144 tests)
- `python3 -m unittest discover -s tests -p 'test_*_unittest.py' -v`: PASS (141 tests)
