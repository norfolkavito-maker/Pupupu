## v0.3.5-test.11

This is a test/staging release that continues Stage 2 (test engine performance) and adds Stage 3 (tray + menu UX).

### Highlights
- Optional **system tray** layer (`pystray`/`Pillow`, lazy imports, Windows-only start) with:
  - status tooltip + colored icons;
  - grouped menu (Основное / VPN / Стратегии / Диагностика / Настройки);
  - background jobs for long actions (single-job lock) + best-effort notifications.
- Tray and menu actions route through `core/commands.py` (no duplicated business logic).
- Added `tray.*` config section (`enabled`, `start_minimized`, `show_notifications`, `refresh_interval_ms`, etc.).
- Added `state.zapret.engine_mode` (auto|winws|winws2) runtime override (does not modify strategy files).
- Strategy/Test menus polished for humans:
  - regrouped items by intent;
  - краткие подсказки;
  - quick access to latest ranking + apply Recommended + save TOP-5;
  - toggle compact/detailed console output via speed settings.
- Conflict validator MVP:
  - detects obvious conflict: multiple UDP/443 + fake QUIC blocks;
  - shows human-readable recommendation (no auto-merge).

### Notes / known limitations
- Tray is optional and does not auto-start unless `tray.enabled=true` in `config.yaml`.
- `close_to_tray` / “Открыть полное меню” from tray remain limited by console app architecture.
- Windows manual validation is still recommended for real pystray backends and notifications.
