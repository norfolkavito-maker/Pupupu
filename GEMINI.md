# DedZapret: Project Instructions & Standards

Этот файл содержит фундаментальные правила и инструкции для разработчиков и ИИ-агентов, работающих над проектом DedZapret.

## 🚀 Основные принципы разработки

1.  **Инструментарий разработки**:
    *   Основной инструмент запуска — `run.bat`. Он автоматически создает виртуальное окружение, ставит зависимости и запускает приложение в режиме реального времени.
    *   **НИКОГДА** не тестируйте изменения через собранный `.exe`, так как он не отражает последние правки кода.

2.  **Архитектурные решения**:
    *   **StrategyManager**: Все операции со стратегиями должны проходить через `ctx.strategies_*`. Используйте индексы для отображения списков (быстро) и `get_strategy()` для получения полных данных (ленивая загрузка).
    *   **Process Management**: При остановке обхода (`stop_zapret`) обязательно используйте агрессивную очистку всех процессов `winws.exe/winws2.exe` по имени, чтобы предотвратить блокировку папок.
    *   **Watcher & Tray**: Эти компоненты работают в отдельных фоновых потоках (`daemon threads`). Изменения в UI должны учитывать потокобезопасность.

3.  **Стандарты кода**:
    *   Используйте `pathlib` для всех операций с путями. Никаких строковых конкатенаций путей.
    *   **Валидация (Preflight)**: Ошибки отсутствия второстепенных файлов (фейки, списки) должны выводиться как `WARN`, а не `ERROR`, чтобы не блокировать запуск `winws`.

## 🤖 Инструкции для ИИ-агентов

1.  **Безопасность**: Никогда не выводите и не сохраняйте содержимое `DedZapretData/data/logs/` без явного запроса пользователя.
2.  **Среда выполнения**: Помните, что проект требует **прав администратора** для работы с `WinDivert` и `hosts`. Всегда проверяйте `is_admin()` перед выполнением системных команд.
3.  **Пути к бинарникам**: Ищите `winws.exe` и `winws2.exe` рекурсивно в папке `runtime/`. Не полагайтесь на фиксированные пути.
4.  **Контекст**: Перед внесением правок в `menus.py` или `main_menu.py`, всегда проверяйте текущее состояние `ctx.state.zapret`, чтобы не нарушить логику отображения статусов.

## 📂 Структура данных (DedZapretData)

*   `data/strategies/generated/`: Стратегии, полученные через импорт (не редактировать вручную).
*   `data/strategies/custom/`: Место для пользовательских стратегий.
*   `data/strategies/index.json`: Кэш-файл для быстрой отрисовки меню.
